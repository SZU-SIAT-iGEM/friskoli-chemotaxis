# Security policy

Security fixes target the latest stable 1.x release. The application is a static browser game with no backend, authentication, or remote score service. It accepts translation JSON and reads local browser records; rendering and validation changes in these areas still warrant review.

Please report a suspected vulnerability privately through [GitHub's vulnerability reporting page](https://github.com/SZU-SIAT-iGEM/friskoli-chemotaxis/security/advisories/new). Include reproduction steps, affected versions, and impact. Avoid publishing exploit details in a public issue before maintainers have reviewed them. Do not include private browser records or credentials.

The team does not promise a fixed response time. Ordinary gameplay bugs belong in GitHub Issues.
