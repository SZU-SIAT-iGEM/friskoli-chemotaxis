# Third-party notices

Friskoli Chemotaxis uses the following direct dependencies. Versions are pinned in `package-lock.json`; each dependency retains its upstream license and copyright notices.

| Dependency | Role | License |
| --- | --- | --- |
| React / React DOM | Browser interface | MIT |
| Vite | Development server and production bundling | MIT |
| @vitejs/plugin-react | React build integration | MIT |
| Tailwind CSS / @tailwindcss/vite | CSS generation | MIT |
| TypeScript | Type checking and test-time transpilation | Apache-2.0 |
| Playwright | Development and CI browser automation | Apache-2.0 |
| @types/node / @types/react / @types/react-dom | Development type declarations | MIT |

Transitive dependencies and browser binaries have their own notices in the installed packages and upstream distributions. The offline application does not download fonts or runtime libraries from a CDN.

Friskoli wordmarks, the mascot, and the cell illustration are team-provided assets. Their separate attribution and rights are documented in [src/assets/NOTICE.md](src/assets/NOTICE.md).
